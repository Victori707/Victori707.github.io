# VIKA — portfolio

Статичный сайт без сборки: HTML + CSS + vanilla JS.

## Запуск
Просто открой `index.html` в браузере. Или локальный сервер:

```bash
cd vika-portfolio
python3 -m http.server 5500   # → http://localhost:5500
```

## Как выложить бесплатно
Этот сайт статичный: здесь нет backend-сервера и сборки через Vite/React/etc. Поэтому его можно бесплатно выложить почти на любой static hosting.

Самый простой вариант без настройки git — **Netlify Drop**:

1. Открой https://app.netlify.com/drop
2. Перетащи туда всю папку проекта или папку с готовыми файлами сайта.
3. Netlify даст публичную ссылку, которую можно отправлять другим людям.

Важно: загружай папку, где рядом с `index.html` лежат `css/`, `js/`, `assets/` и `demos/`, иначе стили, скрипты или картинки могут не открыться.

Другие бесплатные варианты:

- **GitHub Pages** — удобно, если проект уже лежит на GitHub.
- **Vercel** — хорошо подходит для сайтов и frontend-проектов.
- **Cloudflare Pages** — быстрый бесплатный хостинг для статичных сайтов.
- **ChatGPT Sites** — если работаешь здесь со мной, можно сказать: `опубликуй сайт через Sites`, и я подготовлю конфиг, публикацию и дам ссылку.

## Структура
- `index.html` — вся разметка (русский текст — язык по умолчанию)
- `css/style.css` — стили, адаптив, `prefers-reduced-motion`
- `js/i18n.js` — английский словарь + строки, которые генерирует JS
- `js/main.js` — intro, canvas-фон, курсор, анимации, интерактив кейсов, orbit навыков

## RU / EN
Любой текст с `data-i18n="key"` берётся из разметки для RU,
а для EN — из `window.I18N.en[key]` в `js/i18n.js`. Выбор языка запоминается.
